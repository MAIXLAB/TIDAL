# Data sources and access

No datasets are included in this repository. Each user is responsible for requesting and obtaining access, completing any required training or agreements, and following the data owner’s conditions for use and sharing. Access to the code does not grant access to the data.

Some examples use data included with R or R packages, or generate values directly in code. Those examples do not require a separate restricted-data request; install the relevant packages and follow their documentation and terms.

## Input compatibility

- The full PRAMS input, the course PRAMS subset, and the cached full-data R object are different inputs. Obtain the version required by the selected code; do not substitute files based only on similar names.
- The course-compatible NLP notebooks use `train.csv` with `text` and `label` columns. A separate airline-sentiment slide example refers to `Tweets.csv` and `airline_sentiment`; that is a different dataset and is not included here.
- The slides mention a later Mental Stress PPG activity, but a corresponding implementation was not located. No PPG code or dataset is represented in this package.
- The generated SAS import helper expects `prams13f.txt`; request the matching export before using it.
- Keep local input and generated output files out of GitHub. The supplied `.gitignore` excludes common dataset and session file formats. Obtain data yourself; do not upload restricted course data to this repository.

PRAMS access arrangements can change. Check the [current CDC data-access page](https://www.cdc.gov/prams/php/data-research/index.html) and relevant site contacts before requesting data. For course-prepared derivative files, contact the Project TIDAL teaching team via the [project website](https://www.project-tidal.org/).
